Guru Logic Champ Full English Translation
------------------------------------

Description:
 This is an English translation of the Japanese Gameboy Advance game Guru Logic Champ. 


Why:
 The game had enough English in it to be relatively playable so why bother? The translation didn't exist, and it's one of my favorite games of all time. 


Instructions:
 1.) Acquire the no-intro version of Guru Logic Champ (Japan). CRC32 de68f54c SHA-1 77588b6e802de57d1d826c4d43e4c3b0e3aebdae
 2.) Download the .ips file "Guru Logic Champ (Eng v1).ips"
 3.) Use any on or offline patcher to patch the rom.
 4.) Enjoy!


Status:
 100% translated, including all text/art elements, even single pak game mode multiplayer and Champ's Bodyguard.


Secrets:
-There was a name entry you could use in the original Japanese to unlock the whole game. It was in Kanji though. The new secret name is "LOCOM". 
-There is one Japanese character left in the game on purpose. Can you find it?
